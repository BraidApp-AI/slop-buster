# slop-buster promo

Remotion composition for the Twitter/X promo. Brutalist mono typography, vermillion destructive accent, 22 seconds, six scenes.

```
npm install
npm run dev                 # open Remotion Studio
npm run render              # 1920x1080  → out/slop-buster-promo.mp4
npm run render:vertical     # 1080x1920  → out/slop-buster-promo-vertical.mp4
```
